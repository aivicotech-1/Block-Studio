# Costume library and plus menu

The Paint Editor plus button now opens Camera, Upload, Paint and Choose a Costume actions on hover or click. Outside click or Escape dismisses the menu. Paint selects the brush without clearing artwork. Upload accepts PNG/JPEG/WebP/GIF up to 5 MB, normalizes images to embedded PNG, and inserts them on the canvas.

Choose a Costume opens a full-screen library with a purple header, Back, search, category chips and responsive cards. Included categories: All, Animals, People, Fantasy, Dance, Music, Sports, Food, Fashion, Letters and Robot. There are 84 items: original Scout Bear, Alex and Nova Robot poses, fashion/accessory artwork, frames, system emoji illustrations, and A–Z / 0–9 lettering. These are original Block Studio assets, not copies of PictoBlox Tobi, John, Hazel or Isaac artwork. Exact proprietary character files were not supplied.

The Costumes tab has an Add costume button using the same four actions. Choosing or uploading there appends a costume to the current sprite and selects it. The existing Add sprite chooser uses the shared library to create a new sprite. Its menu also includes Camera. Existing backdrop and backpack flows are retained. The standalone Paint workspace remains separate from the notebook.

Browser verification: all 11 filters have results (84/9/5/4/4/4/4/4/10/36/4 in listed order); search/no-match checked; Nova Robot Waving inserted on Paint canvas; upload fixture inserted; Paint switches to brush; Crown added as a sprite costume; Scout Bear Standing added as a new sprite. Mobile and 1280 px desktop galleries visually checked. No captured console errors. Camera capture requires device permission and has not been hardware-tested. Image exports use embedded PNG for project restoration compatibility. Animation poses are separate costumes, not automatic animation clips.

Included in the Paint Editor update.
